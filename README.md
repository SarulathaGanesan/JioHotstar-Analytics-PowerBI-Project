# JioHotstar Data Analysis Dashboard

## Project Overview
This project focuses on analyzing JioHotstar data using Microsoft Power BI. The dashboard provides insights into user engagement, content performance, viewing trends, and subscription patterns through interactive visualizations.

## Project Objectives
- Analyze user engagement and viewing behavior.
- Understand content and genre performance.
- Track viewing trends and audience activity.
- Analyze subscription patterns.
- Present meaningful business insights through dashboards.

## Tools & Technologies
- Microsoft Power BI
- Microsoft Excel
- Power Query
- DAX (Data Analysis Expressions)

## Dashboard Features
- **Overview Dashboard:** Total Users, Total Views, Total Watch Time, and Total Unique Viewers.
- **Content Analysis:** Analyze content performance and genre distribution.
- **User Analysis:** Explore user engagement and viewing patterns.
- **Interactive Visualizations:** Use filters and slicers to explore the data.

## Data Analysis Process
1. Data Collection
2. Data Cleaning and Transformation
3. Data Modeling
4. DAX Measures Creation
5. Dashboard Development
6. Data Visualization and Insights
